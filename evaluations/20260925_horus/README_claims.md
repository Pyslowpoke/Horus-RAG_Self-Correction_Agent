## 建议加入的效果说明

> 2026-09-25 在固定项目文档与合成资料组成的 60 题离线集上，单次真实 API 实验中，纯向量、混合检索、混合检索加核查纠正的完全正确数分别为 48/60、53/60、52/60。评分由 AI 按参考证据进行，尚待人工复核。混合检索与纯向量的正确率差配对 bootstrap 95% 区间为 −3.33 至 +20.00 个百分点，不能据此宣称确定的总体提升。核查纠正未观察到错变对，且一次重写超时丢失原本正确的回答。
>
> 固定证据的生成/核查图耗时 P50 分别为 1.72、1.13、9.79 秒；这不是完整 UI 端到端延迟。主核查流程在 50 道需核查题中有 24 道出错；30 条简单独立核查挑战正确 28 条，不能替代真实回答链路的效果证明。详见独立评估目录。
