# 测试证据记录规则

每次测试在独立日期/运行编号目录保留：目的与预先写下的预期、工具版本和 Git SHA、精确输入及来源（合成/公开/脱敏业务）、执行脚本或手动步骤、带时间的全过程、原始输出和失败、分析与未覆盖范围。

浏览器测试保存 video/trace/截图；API 测试保存脱敏请求、响应、任务状态；模型测试保存提示、模型/提供商、usage、耗时与错误。禁止保存密钥、认证 header 或未经许可的业务数据。规则/假模型/真实模型分别标明。

修复后新建运行，不覆盖原失败；统计包括失败与超时。冷初始化、首字、模型完成、后台完成、页面展示、下载分别计时。API 成功不得称浏览器通过；小样本不得称性能基准。报告提供可打开的 index 和原始文件链接。

本轮完整证据位于本地 outputs/project-audit-2026-10-09；不得未经检查公开业务或本地流量信息。

本轮改进记录：本机工作目录 `outputs/project-improvements-2026-10-09/index.html`，包含录像、trace、输入、脚本、原始模型输出及失败尝试。维护者可本机查看；公开仓库没有这些本机文件，不能将该路径当作在线报告链接。
