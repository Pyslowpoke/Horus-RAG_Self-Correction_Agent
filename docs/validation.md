# 本机验证结果（2026-09-15）

> 本文是上一轮 MiniLM 优化记录。当前中文模型结果见 [中文 Embedding 验证](chinese_embedding.md)。

## 数据与模型

- 原索引 179 条记录、34 种正文；迁移后 34 条。
- 从原始文件按 tokenizer 上限 220 token 重建：62 条记录、62 种正文，全部具有独立 chunk_id。
- 重复入库实测：新增 0、删除 0，总数保持 62。
- Embedding：all-MiniLM-L6-v2，CPU，384 维。
- 重排序：BAAI/bge-reranker-base，CPU，4 线程，批量大小 4，融合候选上限 10。
- 本机最终依赖：transformers 4.51.3、sentence-transformers 5.2.0；pip check 通过。

## 检索对照

以下是优化后同一份索引的开关对照，不是优化前后端到端速度对比。
使用 6 条本地冒烟问题：4 条项目知识问题和 2 条明确不在知识库中的问题。
标注以指定原文片段所在块为相关证据，标注不完整可能影响精度；样本规模不足以代表业务准确率。

| 指标 | 开启重排 | 关闭重排、词项过滤 |
|---|---:|---:|
| 检索 P50 | 4.536 秒 | 0.052 秒 |
| 检索 P95 | 4.652 秒 | 0.055 秒 |
| 标注证据 Recall@5 | 100.0% | 100.0% |
| 返回文档中标注证据比例（4 条问题均值） | 87.5% | 35.4% |
| MRR | 1.00 | 0.75 |
| 无答案正确返回空结果 | 2/2 | 2/2 |

按固定 K=5 计算的 Precision@5 为 20.0%，因为每条问题只有一个标注证据块且允许不凑满 5 条；不能与“返回文档中标注证据比例”混淆。

本次进程初始化（模型、数据库和 BM25）共 46.5 秒，单独记录，不计入上表检索耗时。首次模型加载仍有明显开销，后续请求复用缓存。

早期验证发现 transformers 5.16.1 导入阶段长时间停留于包元数据扫描；4.57.6 的实测组件初始化约 61 秒，最终固定 4.51.3 后本次初始化约 46.5 秒。不同运行的系统缓存状态可能影响数字，不将其视为严格性能实验。

## 验证边界

- 真实本地模型、重排序、向量库、重建及幂等性已验证。
- 33 项回归测试已通过（完整测试集 32 项通过后，新增的身份问答前端测试也通过；前端两项已单独复测）。覆盖检索、核查、预算、网络错误、流式输出和 Streamlit 请求流程。
- LLM 与百度网络集成通过假客户端验证，没有消耗真实 API 额度，也没有测量真实生成/核查总耗时。
- 中文向量模型尚未替换；业务问题集准备好后，按优化说明使用新目录进行对照评测。
- 完整本机检索明细保存在忽略版本控制的 `.evaluation` 目录。
