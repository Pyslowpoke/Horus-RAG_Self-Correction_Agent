# 2026-10-12：引用与纠偏记忆可靠性改进

本轮保持通用资料问答定位，撤回未验证的专用留学文案运营模块。

## 改动

- 在生成、重写和核查后的当前回答上运行引用编号检查，结果进入图状态、超时检查点、界面与导出。即使关闭模型核查也检查编号。不存在的编号不能标记核查通过。
- 支持 `[1]` 和 `[1, 2]` 等编号，忽略 Markdown 链接标签及代码块。检查仅验证编号范围，不能证明引用支持结论、覆盖每条事实或保证回答正确。
- 纠偏 CSV 用标准读写器，保留逗号、换行及引号；重复判断改为来源、完整问题及修正答案匹配，避免前 20 字误判。记录计数按 CSV 记录而非物理行。
- 同进程导入用锁串行化；监听文件修改与原子移动，支持创建事件早于写完正文后的补导入。锁不提供跨进程事务或多用户隔离。
- 核查结果拒绝重复陈述。兼容 API 对空陈述明确返回 `no_claims`，不再把未通过检查的重写答案作为最终答案。

## 验证

合成输入，LLM 与向量库使用替身，无收费模型调用。第一次完整回归 53 项通过；新增兼容 API 保护后定向测试 7 项通过。最后包含引用状态与 UI 的 9 项定向测试全部通过；结果见本机 `work/integrity-2026-10-12/run-03/raw-tests.txt`。全过程与预期保留在该目录不同运行编号中，未覆盖旧记录。

## 仍需解决

长期任务配置、风格与事实资料分离、历史产物管理和语义查重尚未实现。本次可靠性修复不能视为这些能力已经完成。纠偏的新旧答案冲突与时效仍需明确策略；跨进程索引及记忆事务、真实用户效果也未在本轮验证。
